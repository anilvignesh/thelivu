# Thelivu

## Second Brain (om MCP)

This laptop's persistent memory vault lives at `~/second-brain` (Obsidian, `obsidian-mind` template) and is reachable from this repo via the **`om` MCP server** (registered in `.mcp.json`): `search`, `expand`, `recall`, `remember`, `record_work`, `reason`, `health`.

**Before making an architectural or workflow decision in this repo, call `recall` first** (it's scoped to this project automatically) — this repo's autonomy grants, editorial rules, cost-control setup, and infra gotchas were migrated into the vault on 2026-08-22 and may already answer the question. Don't re-derive or re-decide something `recall` would have surfaced.

**After finishing meaningful work — a decision, a shipped feature, a bug with a non-obvious cause — call `remember`** so it reaches future sessions here (and elsewhere, if `scope` is broader than `project`). Do not write into the vault's `memories/` tree directly; go through `om`.

This repo's own docs (`PROJECT-STATUS.md`, `engine/START-HERE.md`, `docs/HANDOFF.md`) remain the authoritative source for Thelivu's actual architecture and current state — the vault holds durable *lessons and decisions*, not a live mirror of the codebase.
